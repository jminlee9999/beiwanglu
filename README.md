# 拾光备忘 · 私人备忘录

一个移动端优先、纯静态的私人备忘录 H5。设计参考 iOS 提醒事项的彩色卡片风格，所有数据只保存在当前设备的浏览器里，不需要服务器、账号或数据库。

适合部署在 GitHub Pages，也可以“添加到主屏幕”像 App 一样离线使用。

---

## 已实现的功能

### 四个分组

- **计划**：支持一次批量添加多个计划；每条可单独设置截止日期和时间（选填）、备注和重要标记，添加图片/视频。每条计划左侧都有待完成圆框，点一下即可打勾完成。
- **已完成**：自动收集所有完成的计划，保留截止时间、附件和完成日期，可恢复为待办。
- **日常记录**：按日期记录文字，可添加图片/视频；已去掉心情选项。
- **好物收藏**：文字 + 图片/视频 + 相关链接；支持图片大图、视频播放、左右切换、置顶和编辑。

每个附件区域最多 **6 个附件**，其中 **视频最多 2 个**；单个视频建议不超过 **20MB**，图片会自动压缩。视频会保存在本机，导出备份时也会一起打包，所以备份文件可能会比较大。

### 细节功能

- **全局搜索**：一次搜索计划、日常记录和好物收藏。
- **本地优先**：数据保存在 IndexedDB；浏览器不支持时自动回退到 localStorage。
- **导出 / 导入备份**：导出为一个 JSON 文件，文字、图片和视频都在里面，方便换手机或防止误删。旧版备份也能直接导入，原图片会自动迁移为新媒体结构。
- **图片自动压缩**：上传时压缩到最长边 1600px，优先使用 WebP，尽量节省手机空间。
- **视频首帧封面**：视频自动截取封面，列表里更容易辨认；点开后可播放、全屏查看。
- **批量新增计划**：一次写下多条计划；留空的计划会自动忽略，每条独立截止时间和附件互不影响。
- **计划卡片直接加附件**：每条计划后面的「图片/视频」按钮可以直接选择图片或视频，不需要进入编辑页。
- **添加到主屏幕**：内置安装引导，PWA 可离线打开。
- **离线缓存**：Service Worker 缓存应用页面和资源。
- **移动端适配**：安全区适配、底部弹层、触摸反馈、键盘可操作、支持减少动态效果；已锁定页面缩放，避免 iOS 键盘弹出或双指手势把页面放大。
- **删除可撤销**：删除后立刻出现的提示里可以点“撤销”。

> 数据是按“域名 / 地址”隔离的。部署地址变了，旧地址里的数据不会自动跟过来；换域名前请先导出备份。

└── README.md

没有构建步骤，没有 npm 依赖，不需要打包。

## 本地预览

不要直接双击 `index.html`，否则浏览器会限制 Service Worker 和部分本地存储能力。建议用一个本地静态服务器：

```bash
cd 李琼的私人备忘录
python3 -m http.server 8080
```

打开 <http://localhost:8080>。

如果你使用 VS Code，也可以装 Live Server 插件后右键 `index.html` → “Open with Live Server”。

## 部署到 GitHub Pages

### 方式一：在网页上上传（最简单）

1. 在 GitHub 新建一个仓库，例如 `my-memo`，选择 Public。
2. 进入仓库，点 **Add file → Upload files**，把这个文件夹里的所有文件上传。
   - 注意保留 `icons/` 文件夹和 `.nojekyll`。
3. 提交后进入仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 里选择 **Deploy from a branch**。
5. Branch 选 `main`，目录选 `/ (root)`，点 **Save**。
6. 等 1～2 分钟，访问：

```
https://你的用户名.github.io/my-memo/
```

### 方式二：用 Git 命令

在项目文件夹内执行：

```bash
git init
git add .
git commit -m "feat: 拾光备忘"
git branch -M main
git remote add origin https://github.com/你的用户名/my-memo.git
git push -u origin main
```

然后同样到仓库 **Settings → Pages** 中选择 `main` / `/ (root)`。

### 部署后检查

- 打开 `https://你的用户名.github.io/my-memo/`，确认页面正常。
- 建议用手机 Safari / Chrome 打开，再通过应用内的
  **数据与备份 → 添加到主屏幕** 安装。
- 第一次打开后，应用会自动缓存，以支持离线打开。
- 如果更新了文件，GitHub Pages 生效后重新加载；若仍是旧页面，可以清除站点数据再试。

## 数据安全说明

- 所有内容仅保存在你的浏览器中，不会上传到 GitHub。
- GitHub Pages 只是托管这个静态页面，看不到你的记录。
- 图片和视频以本地数据形式保存在 IndexedDB，视频越大占用的手机空间越多；长视频建议只存链接，而不是直接上传。
- 清理浏览器数据、卸载浏览器、换手机、换域名，都会导致本地记录丢失。
- **建议定期导出备份**，把 JSON 文件存到网盘或电脑上。
- iOS 的浏览器模式可能在长期不打开后清理本地数据。把应用添加到主屏幕，并定期备份，会更稳妥。

## 可以继续加的功能

如果之后想继续完善，推荐按这个优先级：

1. **密码 / 面容锁**：用本地密码保护隐私（注意：纯前端密码只能防误看，不能替代加密）。
2. **标签与分类**：好物收藏增加“家居 / 穿搭 / 护肤”等标签，方便筛选。
3. **提醒通知**：计划时间到点推送提醒。这需要用户授权，且 iOS 对纯网页后台通知限制较多，通常需要 PWA + 推送服务。
4. **云同步**：接入 Supabase / Firebase，实现多设备同步；但会打破“完全本地”的隐私模型。
5. **回收站**：删除后保留 30 天，而不是只靠即时撤销。
6. **数据统计**：每周完成计划数量、连续记录天数，做成轻量小结。

## 自定义

- 改应用名：搜索 `拾光`，在 `index.html`、`app.js`、`manifest.webmanifest` 中替换。
- 改主色：编辑 `styles.css` 顶部的 CSS 变量（`--blue`、`--orange`、`--rose` 等）。
- 改图标：替换 `icons/` 下的图片，并保持文件名不变即可。
- 改版本缓存：修改 `sw.js` 里的 `CACHE_VERSION`，可以让已安装用户拿到最新静态资源。
